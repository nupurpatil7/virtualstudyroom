About the project

The Virtual Study Room Platform helps learners organize their study activities in one place. Students can join rooms, discuss topics and access learning materials. Administrators can manage the resources available on the website.

This is a student project made using HTML, CSS and JavaScript. Data is stored in the browser for demonstration.
